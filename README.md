# Daily Reflection Tree Assignment

Deterministic Daily Reflection Tool designed for the DeepThought CultureTech Fellowship Assignment.

## Objective

This project creates a structured, non-LLM reflection system for employees using a deterministic decision tree. The goal is to guide daily reflection across 3 psychological axes:

1. Victim vs Victor (Locus of Control)
2. Contribution vs Entitlement
3. Self-Centric vs Others-Centric

The same answers always lead to the same outcomes.

No free-text input.

No LLM runtime.

Only structured branching and reflection logic.

## Design Principle

This system focuses on reflection, not advice.

It helps users notice patterns in:

- ownership
- contribution
- empathy

rather than generating open-ended AI responses.
